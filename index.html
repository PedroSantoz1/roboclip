RoboClip

A desktop tool that turns live stream recordings into vertical short videos.

RoboClip runs on the creator's own computer. It analyzes a recorded live stream, finds its best moments, edits them into vertical (9:16) clips with the webcam and the content arranged for phones, and lets the creator review and select which clips to publish.

Selected clips can be published or scheduled to the creator's own YouTube and TikTok accounts, which the creator connects through the official login of each platform.

How it uses TikTok

  • The creator connects their own TikTok account using TikTok Login Kit.
  • RoboClip shows the connected account's name and avatar so the creator knows where clips will go.
  • Only clips the creator has reviewed and selected are uploaded, using the TikTok Content Posting API, with the caption and privacy setting the creator chooses.
  • RoboClip never posts anything the creator did not select, and never interacts with other users' content.

Who can use it

RoboClip is a personal tool operated by its developer to publish clips to channels they own and manage.
